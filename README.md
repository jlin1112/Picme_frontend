# Picme - an Instagram-like picture-sharing social media web application

URL: https://picme.onrender.com

## Description
- <b>Major technologies used:</b> React, JavaScript, HTML, CSS, Typescript, MongoDB, Express, Node.js, Render
- <b>Picture Sharing Platform:</b> Allows users to share, upload, and discover pictures within the web app community.
- <b>Authentication & Authorization:</b> Implements secured login and registration functionality with email verification.
- <b>User Interactions:</b> Supports liking, commenting, and saving favorite posts.
- <b>Personal Customizations:</b> Offers personal profile, and allows users to edit and delete existing posts, likes, and comments.

### Usage
- feel free to log in using email: <b>testinguser1@testing.com</b> and password <b>testinguser1</b> if you don't want to create an account with a real email address but would like to try out the app
- If you choose to sign up with your email, a verification email will be sent, and most likely it will be in the trash or spam box.
- After logging in, simply click the <b>Create</b> button in the menu on the left to start uploading an image and description.
- After creating, by clicking the image uploaded, you could edit or delete by clicking the buttons at the top. You could also read, write comments, and like the post on the right-hand side.
- You can follow/unfollow other users by clicking their images and use the <b>follow/unfollow</b> button at the top.
- Click <b>Search</b> to search images that contain certain keywords.
- By clicking the <b>avatar</b> or <b>profile</b> button to navigate to account details, where you can see your images, liked images, and followed users.
